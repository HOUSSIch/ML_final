Présentation du projet

Déploiement d'un modèle Machine Learning dermatologique

Cette application transforme le notebook ML en une application web complète. Le backend Flask charge le modèle sauvegardé, reçoit les données du formulaire, applique le pipeline de preprocessing et retourne la prédiction.

01Frontend

Interface HTML, CSS et JavaScript moderne.

02Backend

API Flask avec route de prédiction.

03Modèle

Pipeline ML sauvegardé avec Joblib.
